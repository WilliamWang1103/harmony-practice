# MusicXML 谱例文件夹

本文件夹用于存放用 **Sibelius（或其他制谱软件）导出** 的 MusicXML 格式谱例文档，供「复杂谱例」静态渲染使用。

## 目录结构

```
musicxml/
  01_大小三和弦/          ← 第一章谱例（例 1-25 ~ 1-35 等）
  02_四部和声/            ← 四部和声相关谱例
  03_功能体系/            ← 第二章谱例（例 2-36 ~ 2-41 等）
  04_原位三和弦连接/      ← 第三章谱例（例 3-42 ~ 3-56 等）
  ...（后续章节可继续增加同名文件夹）
```

## 命名建议

- 文件名建议与教材谱例编号对应，例如：`例1-30.musicxml`、`例2-37.musicxml`。
- 一个谱例一个文件；若一个谱例含多行谱表，可在 Sibelius 中合并在同一文档内。
- 文件扩展名统一为 `.musicxml` 或 `.xml`。

## 使用说明（待接入）

1. 用 Sibelius 打开/制作谱例，`文件 → 导出 → MusicXML`，保存到对应章节文件夹。
2. 在 `app.js` 的 `chapterContent` 中通过 `musicxml: '01_大小三和弦/例1-30.musicxml'` 字段引用。
3. 应用启动后 fetch 该文件并渲染为静态五线谱（渲染库方案待定：VexFlow / OSMD）。

> 说明：当前主体应用已统一使用 VexFlow 渲染静态谱例，故 MusicXML 需先转换为 VexFlow
> 音符数据，或重新引入 MusicXML 渲染库（如 OpenSheetMusicDisplay）。具体渲染方案需在
> 提供实际 MusicXML 文件后确定。
